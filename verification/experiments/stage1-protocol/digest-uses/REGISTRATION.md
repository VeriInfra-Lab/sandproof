# 主控公共登记候选

本包独立入口只交付当前六处 digest 值连接；不自行写公共 Lake、根导入、共享原生登记、
根级冻结／输入／累计审计、依赖或覆盖。主控保持单一维护方，将同一采用源码、生成体、
实际文件闭包和普通／原生回执同批接入，再运行当前真实入口；旧根成功不代表新目标通过。

生产采用只将原三处相同表达式放到唯一六行固定库接口。必要 A9/A6/B4 范围为固定具体
`Sha256::digest` 的完整只读输入和原完整 `[u8;32]` 转换，实际接口见
[逐符号记录](fixed-interfaces.json)。条件是有效切片、长度小于 2^61、普通初始化 u8
及库正常完成；域外模型 panic 不是实库失败语义。它不包含任意 Digest、自定义 Drop、
全局摘要单射、任何业务判断或整个 SHA 库机器精化。

公共登记顺序接续既有 Flow→双输入 identity→两参数 SQL→标准 World／重绑定→
标准 identity→标准 SQL 的候选。本包复用的 Raw32／字节／SHA 规格和 canonical 类型
只有一份含义；不要把重复使用的定理名累加为新增性质。实际状态与数字从本包正式
`result.json`、原服务／内核／依赖和严格读回取得，不从模板或 inventory 推断执行成功。

覆盖应分别列：当前采用源码；六处全称完整合同；正常见证；两份真实 Rust 同合同反例；
薄接口机械绑定及其非内核精化边界；普通／原生与共享准入待办。额外空输入摘要清除点、
上层预算、JSON／TLS、SQL／同事务／未知提交／恢复及各具名提供者继续开放。

若公共定义已由主控提供，按相同内容和来源绑定复用；出现不同 canonical 类型时先核对
差异，不能另造一份 World／协议模型。采用或输入变化须核实语义、真实重抽取与受影响
实际文件检查后更新适用范围，不以只刷新摘要迁移旧结论。
