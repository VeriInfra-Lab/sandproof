# 分阶段验证与复核记录

范围：稳定状态发布四类入口、调度八类入口、工作执行十一种命令。
不扩展到最终完成性、数据库、资源适配或部署，不放宽业务检查。
本批纠正了一处模型拒绝原因不一致，具体证据及变更范围见下文。

## 顺序与验收门槛

1. 稳定状态发布：销毁、失败、暂停、运行；完成后统一组合并复核。
2. 调度：资源预留、后续命令安排、停止与回收；完成后统一组合并复核。
3. 工作执行：逐种命令证明成功更新及剩余拒绝分支；完成后整体组合并复核。

每一阶段必须检查：

- 定理针对真实提取函数，拒绝原因和检查顺序一致，而非只证明成功结果。
- 成功结果比较完整后继状态；不能仅比较事件或部分字段。
- 容量、编号和资源索引条件明确列出；不能新增“处理函数正确”之类循环前提。
- 当前尝试与旧尝试的回执严格区分；终止发布核对停止回执及资源关闭。
- 统一控制入口及有限次混合调用证明实际包含新增输入。
- 原有完整验收脚本、真实定理依赖审计与未完成证明扫描通过。
