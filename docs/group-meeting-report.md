# 组会汇报：沙箱控制协议的安全证明与 E2B 一致性审计

> 历史材料说明：本文保留了早期汇报口径，其中“两个真实缺陷”的结论已经撤回。本地 harness 没有锁定完整部署配置、真实节点语义和观察映射，只能支持“候选行为”结论。当前可信结论与缺口以 [项目进展总览](progress-overview.md) 和 [缺口登记表](gap-register.md) 为准。

2026-09。当时的工作建立了沙箱生命周期协议模型，并尝试用本地 harness 对照 E2B；这些对照结果现在仅作为建模与测试材料。

## 一、我们在做什么

沙箱（Firecracker microVM）要经历 创建 → 暂停 → 恢复 → 销毁。真实系统里会出各种意外：命令重复或迟到、请求超时结果未知、controller 崩溃重启、旧资源清理延迟。

我们要保证三件事：

1. **旧实例不复活**：已暂停/销毁的沙箱不能靠迟到命令重新跑起来；
2. **资源不错绑**：恢复出来的实例拿到正确的 workspace、策略、快照；
3. **清理不误伤**：清理旧实例不能删到新实例。

核心洞察：**快照只保存数据，不保存"执行权"**。每次恢复都是 controller 重新签发一次新授权。

## 二、我们做了什么

**1. 形式化模型 + 机器证明（Lean）**
- 一个异步状态机（`World / Step / Reachable`），把"接受请求"和"真正生效"分成多步，显式暴露撤销窗口。
- 两条顶层定理：任意合法历史后状态安全、每一步保持安全。
- 无 `sorry`、无自定义公理，只依赖 Lean 标准公理。

**2. 系统性审计方法**
- 把每条安全性质翻译成源码检查项（guard 表 + 事件/状态映射），逐点算差值，可枚举、可复跑。

**3. 发现并复现 F-1（真实缺陷）**
- 对已暂停的沙箱发 DELETE，接口返回 204（删除成功）并删掉快照；但一个正在进行的 resume 完成后，沙箱又变成 running。
- 在本地控制面环境 3/3 稳定复现，有对照实验。
- 已上报：`e2b-dev/runtime#3636`。

**4. 建了一套"轨迹校验"测试工具**
- 让真实系统跑（含故障注入），记录轨迹，用从模型导出的 checker 判定是否合法。
- 27 条规则、29 个自测；Lean 侧还证明了 checker 的可靠性（接受的合法轨迹一定被接受）。
- 17 个综合场景，其中 F-1 在并发下系统性复现。

**5. 把"模型↔实现"的映射做成可验证的契约**
- 这是关键：模型和真实代码之间的"翻译"本身最容易出错。
- 现在每条映射都带三类证据：现场验证、源码引用、变异测试（故意改错，验证能被抓到）。

**6. 用真实 issue 语料检验完备性**
- 采集 642 条 issue，筛出 317 条相关候选，逐条分类。
- 结论：**边界内的安全问题，全部能被已有性质覆盖**；没有发现"性质管不到"的新安全漏洞。

**7. 第二轮测试又发现 G-1（新缺陷）**
- 如果创建请求被客户端取消/超时，接口报失败，但节点上已经建好的实例不会被回收，成为永久孤儿。
- 确定复现，已上报：`e2b-dev/runtime#3637`。

## 三、发现了什么问题

| 问题 | 一句话 | 状态 |
|---|---|---|
| **F-1** | kill 成功了，但沙箱又被在途 resume 复活 | 已复现、已上报 #3636 |
| **G-1** | 创建请求取消后，节点留下无人认领的孤儿实例 | 已复现、已上报 #3637 |
| **G-2** | kill 之后仍接受 pause（较轻微） | 已复现，记录中 |
| 方法性 | 测试还抓到了我们自己一个映射错误（把会变化的字段当成稳定字段） | 已修正 |

## 四、边界与还没做的

**明确不做的（不是漏洞，是范围）**：
- Linux/Firecracker/磁盘内部行为（只保证传下去的"身份"正确，不证明底层忠实）；
- 多节点、动态网络、fork、自动恢复。

**还没做的（真正的缺口）**：
- **可观察性**：有 12 条性质 checker 还没有数据来源（节点/账本内部状态），所以测不到；
- **活性**：我们证明的是"坏事不发生"，没有证明"请求最终一定完成"（孤儿、清理不完成属于这一类）；
- **实现级验证**：还没有"被证明的实现"，只有被证明的规范。

## 五、结论（可信的说法）

- 协议层的**安全性已被机器证明**，并用它审计真实系统；
- 发现并复现了**两个真实缺陷**，都有最小复现；
- 测试工具链是**从已证明的规范导出**的，映射带可验证证据；
- 对已报告的问题，**边界内的安全性相对完备**；
- **还没**得到"被验证的实现"，**也没**覆盖活性——这两点是后续。
