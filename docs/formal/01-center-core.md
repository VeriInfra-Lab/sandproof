## 1. 实现与模型

对应 [sandbox-center-core](../../sandbox-center-core/src/lib.rs)。新增 unload/resume 前需扩展实际状态与决定，不能把旧 create/renew/destroy 的证明原样标为覆盖。模型只管全局会话、owner、固定节点、期望版本、操作键/全文输入、阶段意图、预留与已确认事实；不远程重写节点 VM 子步骤。

输入是经 V7 规范化但仍需校验的请求、显式时间、V3 绑定回执与 V2 提交结果。输出是拒绝/原结果，或拟提交状态及高级意图；纯函数不发送网络、不创建 VM。全局终止单调；宿主有效撤销和物理停止另有证据。

## 2. 必须证明

| 义务 | 要证明的行为 | 提供方 |
|---|---|---|
| 中心初始化与合法域 | 一宿主/多会话配置非空；编号/期限/资源有界，owner 由授权派生 | V0 类型，V7 鉴权 |
| 操作绑定/重放 | 已有键全文相同返回同操作；不同拒绝；新键才检查窗口/版本/状态；过期不分配替代身份 | V0/F1，V2 持久窗口 |
| 意图串行与终止 | 普通转换按会话版本串行，destroy 单调否决未来开始；迟到结果不复活终止会话 | V3 当前回执 |
| 预留转换 | Running→Pausing 暂不释放运行资源；Unloaded 只转出已证释放分量；Resume 先预留新运行与旧 backing 重叠 | V6 物理事实，V5 本地保留 |
| 发布忠实 | Accepted 不变 Ready；仅匹配当前操作/代次的事实驱动相应结果，终态历史不授予当前访问 | V2 耐久保存，V3 身份/阶段 |
| 准入完整 | 支持域且状态/资源/版本充分时能接受正常操作；保留内部终止/结算容量 | V0 有界算术 |

创建固定节点，恢复保持同一节点与逻辑会话。总寿命沿原起点和上限，不因 pause/resume 或管理重启延长。终止可以改变用户状态保存义务，但不能释放未知资源责任。

## 3. Rust 对应与验收

沿原 Aeneas 抽取实际决定、检查和预留转换，证明输入/输出/状态表示关系以及修改范围。模型当前未包含的新字段需连到实际类型；不能只对手写 Lean 转移证明。

原正常/冲突/过期/耗尽/回执迟到及 destroy 竞争必须有同性质样例。接 V2 的提交后派发和 V3 收件，提供 LC-P1/2/8/9/11 的中心部分；最终系统性质由 V9 组合。实际全量 get/list、跨节点调度、模板平台及完整中心容量不在此阶段任务。
